# Preserved generator source

This folder preserves the local camera-mount generators, configuration and source provenance as read on 2026-10-23. The six latest STEP/STL outputs remain in the parent folder from commit `161090e72e86a324802615fd9594d1cf16f65668`.

The generators were not executed during preservation. Paths and previous validation statements inside the original files are historical records, not fresh validation. Physical fit, print completion and hardware operation were not checked.

Third-party reference geometry, vendor manuals and downloaded packages are not republished here. See `sources/provenance.json`, `sources/ros_commit.json` and the upstream README for source references. Reproduction requires retrieving the cited reference assets and preparing the original dependencies. No printer connection information, private photos, credentials or runtime environments are included.
