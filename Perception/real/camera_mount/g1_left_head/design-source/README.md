## 公式データから分かったこと

1. [Unitree公式ROSモデル](https://github.com/unitreerobotics/unitree_ros/blob/master/robots/g1_description/meshes/head_link.STL) の `head_link.STL` とURDFを取得しました。URDFのメートル単位から1000倍してCADのmmへ変換しています。頭部メッシュには首元の外装も含まれ、外形全体は約 **140.340 × 155.591 × 205.777 mm** です。これは頭頂部だけの寸法ではありません。
2. このメッシュから、ご指定の**左側2本のネジ穴の中心・ネジ径・有効深さは特定できませんでした**。外形モデルを計測しても、存在しない穴の製造寸法は復元できません。
3. [Unitree公式 `xr_teleoperate/Device.md`](https://github.com/unitreerobotics/xr_teleoperate/blob/main/Device.md) にはClassic Head (98mm) / Renewed Head (88mm) の別と、カメラブラケット用M4×16を2本使用する記載があります。
4. そこからリンクされている両方の公式STEPを読み、φ4.5 mmの穴の軸位置が旧型でY=±49 mm、新型でY=±44 mmと確認しました。したがって穴間隔は98 / 88 mmです。ただしこれは**左右のカメラブラケット用2穴**で、ご指定の「左側だけの2穴」の間隔ではありません。STEPの座標系も頭部STLと位置合わせされていません。
5. レールは[米国政府発行MIL-STD-1913図面の公開コピー](https://combatrifle.net/pdfs/picatinny_1913_specs.pdf)のFigure 1 / 2を参照しています。原文PDFを `sources/` に保存しました。レール形状の参考資料であり、ロボット用途で規格認証済みという意味ではありません。

プレートと本体を分離し、G1側の寸法が分かった時にプレートを設計し直せるようにしました。プレートの4穴は**本体をつなぐM3穴**です。G1のM4穴位置ではありません。M3×10のキャップボルト4本とM3ナット4個が内部締結の候補ですが、実際の頭径・頭高・ナット寸法とプリント誤差を試作時に確認する前提です。

## 計算で確認した範囲

- 本体、プレート、試験片はそれぞれ単一の有効ソリッド、全シェル閉鎖。
- STEP再読込後の単一ソリッド・有効性・体積一致。
- STLの全辺が三角形2枚に共有される閉じたマニフォールド。退化三角形なし。
- 本体とプレートの体積干渉0 mm³、内部締結用4本の軸の通り。
- 仮配置（頭部メッシュ座標mmの `[0,60,495]`）では、取付構造のX/Z外形区間に重なる頭部三角形の最大Yから、プレート内側までのY方向隙間は約3.948 mm。ただし**接触面の設計が完了したという意味ではありません**。実際には穴位置・座面に合わせて配置し直します。

FEM・荷重試験・ネジ座面強度・プリント層間強度・既存LiDAR/カメラ/マイクの遮蔽・腕の動作干渉は未評価です。`physical_ready=false`、`print_release=false` を記録しています。頭部を外さず取り付けられるかも、ネジ位置が分かるまで未確定です。

## 実機用に仕上げるための必要情報

`config/measurement_request.json` に未確定項目をまとめました。最初にあると有効なのは次の情報です。

1. **左側頭部と下面の写真**：取り付けたい2本のネジ、周辺の外装・センサが分かるもの。写真でネジを特定し、寸法自体はノギス等で確認します。
2. **2本の中心間距離と方向**：前後／上下、同一平面か、ネジ軸が横向きか上向きか。頭径が同じ2本なら同じ側の端同士の距離も中心間距離の参考になります。
3. **ネジの規格・元の長さ・座面**：M4かどうか、ピッチ、頭の形、現在の座面から先の長さ、底付きまでの余裕。未確認なら空欄のままで構いません。
4. **G1の型式・購入時期、新旧頭部**。
5. **カメラ等の機種と合計重量、クランプ外形**。本体の重さに加えて、外側に離れた重量による曲げを評価します。

ネジの長さは単に「長め」で決めず、まず `新しい首下長さ = 元の首下長さ + 追加した締結厚さ` を基準に、元のねじ込み量を保てるか確認します。実際に加わる座面厚さ・ワッシャー・既存部品の扱いにより変わります。公式カメラブラケット用のM4×16を、この側面マウントにも使えるとは判断していません。

先に試す場合は30 mmのレール試験片で手持ちクランプの嵌合を確認できます。材料・向き・積層条件が未指定なので、実機運用部品の材料や印刷設定はまだ確定していません。フルサイズを印刷しても、このv0のブランクプレートにはG1へ固定する機能はありません。
